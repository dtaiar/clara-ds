# Clara DS — app (Vertical Slice 01 checkpoint)

React + TypeScript + Vite + Panda CSS, scaffolded for Slice 01 ("Intent-first Discovery").

This is the first implementation checkpoint only — see `decisions/ADR-002-theme-architecture-slice-01.md`
at the repo root for the theme architecture this proves, and `docs/slices/01-intent-first-discovery.md`
for the slice this belongs to. It is not the Explorer UI.

## Commands

```bash
npm install
npm run dev      # local dev server
npm run build    # type-checks and builds; regenerates styled-system/ via the `prepare` script
```

`styled-system/` is generated by Panda CSS and is gitignored — never edit it directly.
